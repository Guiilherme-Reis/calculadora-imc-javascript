# 🧮 Calculadora de IMC

Projeto desenvolvido durante meus estudos de JavaScript para praticar manipulação do DOM, eventos e validação de formulários.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📋 Funcionalidades

- Cálculo automático do IMC
- Validação de peso e altura
- Classificação do resultado
- Exibição dinâmica na tela

## 📚 Conceitos praticados

- addEventListener
- querySelector
- Manipulação do DOM
- Criação dinâmica de elementos
- Funções
- Condicionais
- Template Strings
